# Monet

Monet is an open-source chat application focused on simple, expressive conversations.

The project is intended to provide a clean foundation for real-time messaging, user-friendly conversation flows, and a developer-friendly codebase that can be extended by the community.

## Status

Monet is in early development. The repository is being initialized, and the application structure will evolve as the core chat experience is built out.

## Goals

- Provide a fast, approachable chat experience.
- Keep the codebase simple enough for contributors to understand.
- Support open-source collaboration from the start.
- Build practical features before adding unnecessary complexity.

## Contributing

Contributions are welcome. If you want to help, open an issue or pull request with a clear description of the change you want to make.

Before contributing, please keep changes focused and easy to review.
